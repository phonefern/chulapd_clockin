# Requirement: Monthly Attendance Certification Report

## เป้าหมาย

ปรับหน้า Export ของ **ChulaPD Attendance** ให้เป็น **รายงานรับรองการปฏิบัติงานประจำเดือน** ที่ดูเป็นเอกสารทางการ สวย อ่านง่าย และพยายามจบภายใน **A4 จำนวน 1 หน้า**

---

## 1. รูปแบบเอกสาร

แนะนำ **A4 Landscape** เพื่อรองรับข้อมูล 28–31 วันในหน้าเดียว

Design:
- Minimal / Professional
- พื้นหลังขาว
- ใช้สีหลักของ ChulaPD เล็กน้อย เช่น น้ำเงินเข้ม
- Typography ชัดเจน
- ลดพื้นที่ว่างที่ไม่จำเป็น
- ตาราง Compact แต่ยังอ่านง่าย
- ไม่มี Browser Header / Footer / URL / `localhost` / เลขหน้าจาก Browser

---

6. Verification
เตรียมรองรับ QR Code ด้านล่างขวา
/verify/{verification_id}

หน้า Verify แสดง:
- ชื่อเอกสาร
- พนักงาน
- เดือน
- ผู้รับรอง
- วันที่รับรอง
- Verification ID
- สถานะเอกสาร
- Document hash
QR Code สามารถทำภายหลังได้ ไม่จำเป็นสำหรับ MVP
7. One-page Print Requirement
เป้าหมาย:
รายงานพนักงาน 1 คน / 1 เดือน / 1 หน้า A4

แนะนำ Print CSS:
@page {
  size: A4 landscape;
  margin: 10mm;
}

ต้อง:
- ลด whitespace
- ไม่ให้ table row แตกข้ามหน้า
- Header และ Approval อยู่หน้าเดียวกับตาราง
- ลดขนาด font อัตโนมัติเล็กน้อยกรณีเดือน 31 วัน
- ซ่อน UI เช่น Button, Navbar, Sidebar ตอน Print
- ซ่อน Browser print header/footer เท่าที่ระบบควบคุมได้
หากข้อมูลหมายเหตุยาว ให้ truncate ในรายงาน และเก็บรายละเอียดเต็มในระบบ
